# antisocialcord
A pure Kotlin library for communicating with the Android version of Discord, reverse-engineered from the official SDK from Discord (known as the "Social SDK", hence the joke name)

## Features
* Allows sending an activity update (setting a rich presence) with *zero configuration* on the user-side! The user only needs the Discord app installed.
